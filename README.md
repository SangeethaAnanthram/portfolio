## ✨ Key Features

- **Futuristic Cyberpunk / Dark Glassmorphism UI:** Deep navy/cyan aesthetic with neon glow effects, frosted glass surfaces, and responsive typography.
- **Dynamic Floating Orbs & Particle Canvas:** Self-injecting background animation featuring 5 organic drifting glowing spheres and a subtle interactive particle constellation.
- **Typing Hero Animation:** Dynamic title switcher showcasing key skillsets (*Data Science Student*, *Python Developer*, *Data Analyst*, *Web Developer*).
- **In-Depth Project Modals:** Dedicated case studies with problem statements, architectural solutions, technology tags, and screenshot galleries:
  - 🩺 **Medicine Recommendation System:** ML-driven symptom diagnosis and medication advisory platform.
  - 📊 **Smart Finance Insights:** FinTech predictive budgeting, classification, and analytics dashboard.
  - 📚 **StudySync Collaboration Hub:** Real-time peer learning workspace with synced Pomodoro timers and flashcards.
- **Interactive Credentials & Certificate Lightbox:** One-click modal viewer displaying official certificates, dates, and verification IDs:
  - GVKSS Software Pvt. Ltd. (AEM & Python Internship)
  - Infosys Springboard Virtual Internship Badge
  - Infosys Springboard Basics of Python Certification
  - Infosys Springboard Introduction to NoSQL Databases Certification
- **Interactive Experience & Education Timelines:** Structured milestones from B.Tech in Data Science at Sri Indu College to industry internships.
- **Animated Skill Progress:** Scroll-triggered animated progress indicators for Python, SQL, Machine Learning, Data Analysis, and Web Tech.
- **Zero-Dependency Architecture:** 100% pure client-side code — no npm packages, node modules, React, Vue, Bootstrap, or Tailwind required.

## 🚀 Getting Started Locally

No compilers, build tools, or server environments are needed to run or edit this portfolio.

### Option A: VS Code Live Server (Recommended)
1. Clone or download this repository.
2. Open the folder in **Visual Studio Code**.
3. Install the **Live Server** extension (by *Ritwick Dey*).
4. Right-click on `index.html` and click **"Open with Live Server"**.
5. Your browser will automatically launch `http://127.0.0.1:5500/index.html` with hot-reloading.

### Option B: Direct Browser Launch
Simply double-click `index.html` in your file explorer to open it directly in any modern browser (Chrome, Edge, Firefox, Safari).

## 📤 How to Deploy to GitHub Pages

1. **Create a Repository:**
   - Go to [GitHub](https://github.com) and click **New Repository**.
   - Name it `portfolio` or `<your-username>.github.io`.
   - Set visibility to **Public** and leave initialization options unchecked.
2. **Push or Upload Files:**
   - Push your code using Git:
     ```bash
     git init
     git add .
     git commit -m "Initial commit: Futuristic Portfolio"
     git branch -M main
     git remote add origin https://github.com/<your-username>/<your-repo-name>.git
     git push -u origin main
     ```
   - *Alternatively:* Click **"Add file" -> "Upload files"** on GitHub, drag `index.html`, `style.css`, `script.js`, `README.md`, and the `assets/` folder, and commit changes.
3. **Enable GitHub Pages:**
   - In your repository, click **Settings** ⚙️.
   - Go to **Pages** in the left sidebar.
   - Under **Build and deployment > Source**, select **Deploy from a branch**.
   - Under **Branch**, choose `main` and folder `/ (root)`, then click **Save**.
   - Within 1–2 minutes, your portfolio will be live at:
     ```
     https://<your-username>.github.io/<your-repo-name>/
     ```
